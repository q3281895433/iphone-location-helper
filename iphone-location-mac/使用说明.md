# 定位助手 0.5.1 · 卫星地图与坐标适配

首次使用请按仓库根目录 README 安装依赖并构建，再双击上一级目录的 **定位助手.app**。保持旁边的 **iphone-location-mac** 支持文件夹原位，里面含运行环境和应用源码。这是 macOS 应用。

## 连接真实手机

应用启动会读取 USB 设备列表，显示手机实际名称、iOS 版本和标识末四位。只有检测到一台设备时才自动连接其定位服务，不会自动修改位置；多台设备时请在下拉列表选择，再点击“连接所选手机”。

未检测到设备时，会显示“未发现 USB 设备”。用数据线连接手机，解锁并信任 Mac，再点击“刷新”和“连接所选手机”。连接成功后，窗口显示实际手机名称与“原生定位服务已连接”。正在模拟时，需先恢复当前手机的真实定位才能切换设备。

固定定位与恢复曾在开发设备上验证。0.5.1 增加底图坐标适配，但地图编辑、设备身份校验及完整路线下发仍需分别核对，不能认定已消除用户手机上的位置偏移。使用时请在手机地图核对结果。

## 先选择底图坐标

地图提供两个手动选项：默认的“大陆底图校正 GCJ02”和“原始 WGS84”。这不是自动检测地图供应商、当前位置或国界。使用大陆高德坐标底图时选择前者；国外、非大陆底图及港澳台等不适用该校正的地区选择“原始 WGS84”，再核对实际场地。校正中的经纬度包围框只是粗略适用范围，不能准确排除港澳台及邻国。

校正模式将地图点击、拖动得到的底图坐标转为 WGS84，再用于手机；地图上的路线、搜索标记、已发送位置与“适应路线”则按相反方向转换显示。手工输入的经纬度、搜索结果、路线配置和设备后台始终使用 WGS84，不随显示模式改变。

切换模式只改变地图投影，保留已选 GPS 坐标，不会自动修正此前选错的位置。请在选定正确模式后重新核对并重新选点。应用不保存旧路线；升级到 0.5.1 后请重新选择操场、调整跑道，先用固定定位在 iPhone 自带“地图”中核对落点，再开始跑圈。若固定定位仍在其他地方，先恢复真实定位，不要继续回放该路线。

转换使用公开近似模型。内部数值往返回归小于 0.1 米，只说明同一模型的正反计算相容，不代表地图实际位置、手机 GPS 或第三方应用有同等精度，也不代表已完成本版本真机验证。

## 地点搜索

1. 在地图上方的搜索框输入城市、地址或地点名称，按回车或点击“搜索”。建议带上城市，例如“北京 奥林匹克公园”。
2. 从下方列表选择正确结果，地图会移到该地点，橙色标记表示搜索结果；左侧经纬度同时填入该结果的 WGS84 坐标。
3. 搜索只用于选择位置，不会直接修改手机定位。可以继续在地图选起终点，也可以点击“设置固定定位”。

启动时经纬度为空，不再提供固定学校预设。搜索由 OpenStreetMap Nominatim 提供，需要联网；仅在按回车或点击搜索时发送输入的地点名称，每次请求至少间隔 1.1 秒，并缓存本次会话的结果。搜索记录不写入本工具的日志或配置，设备标识不会随查询发送。可通过 `map/search-provider.json` 更换兼容的 HTTPS 搜索服务。

应用已有专用蓝绿色定位图标。程序坞快捷方式指向当前应用位置；请保持应用与支持文件夹相邻，移动应用后需重新添加快捷方式。

## 在真实地图选择起点和终点

1. 保持 Mac 联网，等待 Apple 卫星影像加载，先选择适用的底图坐标模式。可切换混合地图查看道路与地名。先使用搜索框找到地点，也可自行拖动缩放地图。
2. 选择“地图路线”模式，点击地图工具条“选起点”，再点击地图上的实际起跑地点。
3. 点击“选终点”，再点击终止地点。之后可点击“加途经点”，沿期望路线依次补点；可拖动标记微调，或用“撤销”“清空”修改。
4. 蓝色线按 **起点 → 按添加顺序排列的途经点 → 终点** 连接。这是手动绘制路线，没有道路导航或自动绕障碍功能。绕圈时沿跑道依次加点，最后将终点选在起点附近；不要只选两个点就期待自动贴合跑道。
5. 先用固定定位核对实际落点，再设置配速、检查路线和长度，连接真实手机后点击“开始路线”。地图路线只从起点走到终点一次，周长、半径、圈数和方向字段仅用于“椭圆跑圈”模式。
6. 可暂停或继续。运行时选点被锁定；到达终点后保持定位，点击“恢复真实定位”结束。

地图里的移动圆点是程序已发送的模拟位置，不是手机返回的实时 GPS 读数。手机是否采用该位置仍需在手机地图核对。后端与坐标输入使用 WGS84；请勿将其他地图的 GCJ-02 或 BD-09 坐标直接作为 WGS84 输入。

地图由原生 [Apple MapKit](https://developer.apple.com/documentation/mapkit/mkmapview) 提供，影像需要联网；系统会向地图服务请求当前可视区域的数据。底图无法加载时不要依据空白底图选点。选点和设备标识不发送到业务中转服务器。

中国区域可能使用不同的地图数据服务，底图位置与 GPS 坐标的兼容性需核对。Apple 将 [`CLLocationCoordinate2D`](https://developer.apple.com/documentation/corelocation/cllocationcoordinate2d) 定义为 WGS84；[高德坐标说明](https://developer.amap.com/api/javascript-api-v2/guide/transform/convertfrom)说明其地图使用 GCJ-02。这些定义不能替代本机地图显示与手机实际落点的核验。请结合已知场地检查位置，不要仅凭桌面跑道和蓝点重合就认定真机定位准确。

## 固定定位与恢复

1. 用数据线连接 iPhone，解锁并信任此 Mac，保持开发者模式开启。
2. 在真实设备列表选择手机，点击“连接所选手机”。
3. 输入 WGS84 纬度和经度，点击“设置固定定位”，然后在手机自带地图中核对。
4. 需要结束时点击“恢复真实定位”，再在手机地图中核对真实位置。

地图选点或搜索结果会填入左侧经纬度；请确认位置后再设置手机定位。

本工具使用原生设备通道 `--native`，兼容性随 iOS 与设备库版本变化。

## 跑圈怎么实现

程序按“两条直道 + 两端半圆”构造闭合跑道，再根据配速与经过时间计算每秒的位置，通过同一个原生设备通道发送给手机。

1. 选好底图坐标模式，选择“椭圆跑圈”，点击地图上的“固定点 / 跑道中心”后重新选择实际运动场中心，或输入 WGS84 经纬度。不要复用此前发生偏移时的选点。
2. 在地图上直接拖动跑道的四个手柄：**紫色**手柄移动中心；两个**橙色**手柄分别调整长轴和短轴；**青色**手柄旋转跑道。长轴、短轴改变时会同步更新周长和弯道半径，旋转时同步更新旋转角。
3. 也可以在左侧输入跑道周长、弯道半径和旋转角，地图会同步更新。**0° 表示长轴朝北，90° 表示长轴朝东**。400 米与 36.5 米只是默认模型参数，不保证和某个真实场地重合。
4. 设置圈数和配速。例如 5 圈 × 400 米、6:00/km，总运动时间约 12 分钟。
5. 先点击“设置固定定位”，在 iPhone 自带“地图”核对是否到达场地中心；核对正确后再点击“开始跑圈”。程序每秒更新一次位置，跑圈起点位于跑道边缘而非中心。运行时跑道拖拽和参数编辑锁定；暂停时保持当前点，运动时间、距离和模拟步数停止累计，继续后从原进度接着运行。
6. 跑圈结束后保持在终点，点击“恢复真实定位”结束模拟。

紫色跑道是根据输入参数叠加在真实地图上的几何模型，不保证与地图中实际跑道重合；请核对场地、半径和角度。跑圈几何与设备状态控制有自动测试，地图手柄操作和完整真机跑圈需要单独验证。

## 电脑、步数和服务器

- 运行过程中不需要持续点击电脑；保持 Mac 开机、设备连接及应用运行。模拟会话期间应用会请求禁止 Mac 空闲休眠。
- “模拟步数”只按运动时间和输入步频估算，便于核对配速模型，不会写入系统传感器步数。
- 当前实现依赖 Mac 的可信设备连接。把控制页面放到服务器，不能直接把这个 USB 方案变成脱离电脑的全局定位工具。普通 iOS 应用权限也不能覆盖其他应用使用的系统位置或计步数据。
- 固定定位和跑圈不需要业务中转服务器；首次部署需通过 setup.command 安装 Python 依赖。

## 退出和异常

正常退出会尝试停止跑圈并清除模拟定位。若设备断开或恢复操作报错，重新连接后点击“恢复真实定位”，并在手机地图核对。不要依赖强制结束进程或拔线来恢复位置。

源码：App.swift（原生界面）、PlaceSearch.swift（地点搜索）、MapCanvas.swift（原生地图与编辑交互）、IconPainter.swift（图标绘制）、backend.py（真实设备会话）、route_geometry.py（轨迹与计时）。搜索服务配置为 `map/search-provider.json`，运行环境为 `.venv`。自动测试使用模拟对象；正式应用只枚举和连接实际 USB 设备。

上游设备库为 [pymobiledevice3 11.34.1](https://github.com/doronz88/pymobiledevice3/releases/tag/v11.34.1)，使用其原生设备通道和 DVT 位置模拟服务。

0.5 起使用 Apple 原生 MapKit 的[卫星影像](https://developer.apple.com/documentation/mapkit/mkimagerymapconfiguration)与[混合地图](https://developer.apple.com/documentation/mapkit/mkhybridmapconfiguration)，0.5.1 增加手动底图坐标适配。0.4 曾集成 [Leaflet 1.9.4](https://github.com/Leaflet/Leaflet/tree/v1.9.4)，`map/vendor` 保留历史资源与 BSD-2-Clause 许可证；当前运行地图不使用这些资源。来源和许可证见 [OPEN_SOURCE.md](OPEN_SOURCE.md)。
